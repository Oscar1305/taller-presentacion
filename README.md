# Taller · Presentación del proyecto

Web de presentación de un proyecto personal en desarrollo para talleres de motos y coches.

**Ver la web:** https://oscar1305.github.io/taller-presentacion/

Incluye ejemplos interactivos ficticios de mantenimiento y reparación con esperas de recambios. El nombre Taller es provisional. No es una aplicación comercial disponible ni una demo conectada a datos reales.

Este repositorio contiene únicamente los archivos públicos de presentación. `index.html` es autónomo: estilos, iconos y ejemplo interactivo incluidos, generado con Astro. `.nojekyll` permite servirlo directamente desde GitHub Pages.

Para verlo sin conexión, descargar `index.html` y abrirlo en un navegador. No hace falta instalar dependencias.

Diseño actualizado siguiendo la referencia visual aportada al proyecto. Tipografía Geist incluida bajo SIL Open Font License 1.1; el texto íntegro de su licencia está incorporado en `index.html`. Los ejemplos mantienen diagnóstico, esperas y calidad antes de recogida. La web no contiene formulario de contacto.
